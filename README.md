# Roomie Swipe

Ideen er en  app til at finde roomies. Du opretter en profil og swiper dig igennem andre profiler. Til sidst kan du se dine matches i en liste.

## Sådan starter du appen

1. Download/klon projektet
2. Åbn en terminal i mappen og kør:

3. Start appen:
```
npm install
```
4. Scan QR-koden med Expo Go 

## Skærme fra G1
- Login
- Opret profil
- Swipe
- Matches

## Funktionaliteter
- Login og database: oprettelse, login og profiler gemt i Firebase 
- Kamera: tag eller vælg profilbillede 
- Kort: viser bydelen, værelset ligger i 
- AI-profilhjælper: AI skriver din bio 
- Profil-menu: rediger profil, svar og bio 
- Menu i bunden: Find roomie, Matches og Profil
