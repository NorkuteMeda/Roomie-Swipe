# Roomie Swipe

Ideen er en  app til at finde roomies. Du opretter en profil og swiper dig igennem andre profiler. Til sidst kan du se dine matches i en liste.

## Sådan starter du appen

1. Download/klon projektet
2. Åbn en terminal i mappen og kør:

3. Start appen:
```
npm install
```
4. Scan QR-koden med Expo Go 

## Skærme fra G1
- Login
- Opret profil
- Swipe
- Matches
